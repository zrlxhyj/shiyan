# 方法核验与实现边界

核验日期 2026-10-20。本文档区分稿件公式、原算法实现与检测适配，避免用同名方法掩盖差异。

## FedDecouple

依据稿件式（9—18）、（24—30）、（32—37）实现。最后一层常规查询已经由官方 decoder 从 denoising 查询中拆分。近端项使用 `pred_logits`、`pred_boxes`，不使用 `dn_aux_outputs`。任务损失仍由官方 SetCriterion 计算，保留辅助和去噪损失。

教师 eval、无梯度；学生 train。二者运行模式差异可能使同参数初始近端项非零，与稿件说明一致。近端前向的 BN 和 RNG 会恢复，任务前向每步保留一次统计更新。参数使用保存副本恢复，随后只调用一次 optimizer.step。

探测任务损失重新执行原生匹配，不强行固定为近端匹配。因此实现符合训练算法，但不能声称所有真实步骤满足命题中的固定任务匹配假设。

## FedSOL

官方固定版 ClientTrainer 使用 softmax KL、温度 3，随后 SAM 风格任务更新；不是参数 L2。本项目将所有常规查询当作分类比较单元，按查询取平均，保留同编号比较，不加入检测框知识。该适配容易受到查询身份切换影响，正是需要明确报告的基线选择，而不是原论文现成的 RT-DETR 方案。

自适应版进一步使用 `normalize(abs(w-w_ref), p=2, dim=0)` 调制扰动。本项目没有将它与固定半径主基线混在同一标签下。原算法 BN 前向策略与稿件不同，本项目对所有探测方法统一采用稿件规定的一次任务前向统计。

## FedHyper

参考官方 `federated_main.py` 和 `update.py`。G 对累积内积 agg 裁剪到 [-0.8,4]，步长 1+agg。GM 将历史方向递推为当前方向＋0.9×历史方向，agg 范围 [-0.2,4]；更新还含 0.9×agg×历史方向。FULL 同时启用 CL：跳过每个 epoch 首 batch，对参数移动的局部/全局内积更新乘数，并限制乘数在 [0.1,10]。

官方分类代码中若干数据、评价与路径问题没有直接照搬。检测器和数据管线使用统一实验框架；本地优化器和样本权重按实验协议统一。所有这些结果应称为检测任务适配结果。

## 未接入的两种扩展对照

| 方法 | 已核实内容 | 暂不生成结果的原因 |
|---|---|---|
| FedUD | DOI 10.1007/s00530-026-02489-2；稿件描述含 UODNet、层冻结和历史正则 | 本次未核验可直接运行的官方训练代码；结构改变需要说明与统一 RT-DETR 比较的条件 |
| FL-JSDDC | 公开论文方法基于 YOLOv8n，包含本地历史知识、自蒸馏与漂移补偿 | 本次未核验作者代码；需要明确 RT-DETR 输出/通道语义迁移，不能用一项 KL＋偏移公式冒充完整方法 |

这不是声称这些论文没有代码，仅说明本次尚未核实具备可复现实验条件。

## 公平比较要求

固定数据清单、模型版本和预训练权重；每个种子配对复用参与序列和客户端 RNG；所有直接比较使用相同本地优化器、步数规则、输入和增强。不同局部计算量需同时报告时间。SCAFFOLD 的无动量 SGD 是单独比较组，不能直接将其结果归因于算法而忽略优化器差异。FedBN 的本地模型评价口径单列。

主表填写固定预算最后一轮，best_dev 作为补充。未达到目标精度应写“未达到”，缺失实验写“未完成”，不能以零或最大轮数代替。
